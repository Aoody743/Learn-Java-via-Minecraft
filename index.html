Roadmap

阶段 1-5 学习路线

完整覆盖 Java 基础、插件开发、交互挑战、后端 Docker 沙箱和 MOD 原理课程。

阶段 1

Java 基础 MVP

变量、判断、循环、方法、类、集合和事件思想。

阶段 2

Paper 插件开发

插件结构、plugin.yml、命令、监听器、配置、定时任务。

阶段 3

交互挑战系统

选择题、填空题、代码补全题、即时反馈和经验奖励。

阶段 4

Java 代码沙箱

后端编译运行、Docker 隔离、资源限制、自动测试用例和排行榜。

阶段 5

MOD 原理课程

Forge / Fabric、方块、物品、事件总线、资源、数据包和客户端/服务端。

Stage 1

Java 基础交互课程

选择课程后阅读场景解释、Java 概念和代码示例，并标记完成进度。

Stage 2

Paper / Spigot 插件开发阶段

把 Java 基础迁移到真实服务器插件结构，学习主类、事件、命令、权限、配置和小插件实战。

Stage 3

任务挑战系统

完成选择题、填空题和代码补全题，系统会即时判定答案、显示错误提示、累计任务积分并解锁成就。代码编辑区优先加载 Monaco Editor，失败时自动降级为普通编辑器。

XP：0

Stage 4

Java 代码沙箱

支持调用本仓库的 Node 后端编译运行 Java。后端使用 Docker 隔离、网络关闭、CPU/内存/时间限制和自动测试用例；未启动后端或 Docker 不可用时，前端会显示明确错误。
